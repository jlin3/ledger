Privacy policy

Ledger · last updated October 16, 2026

Ledger is a personal app used by one person, its owner, on their own Mac. It is not offered to anyone else.

Data Ledger accesses

With the owner's permission, Ledger has read-only access to the owner's Gmail (Google scope gmail.readonly). It searches only for email from the owner's banks and card issuers.

How the data is used

  • Email is read in memory to pull out amounts, dates, balances and account endings, which update the owner's own budget and bill tracking.
  • Email bodies are never stored. Ledger keeps only the extracted numbers and the message ID, so it doesn't read the same email twice.
  • Ledger never sends, modifies, labels or deletes email.

Storage and sharing

  • All data stays on the owner's computer, in a local database. The Google sign-in token is kept in the macOS Keychain.
  • Nothing is sent to any server other than Google's own Gmail API. Ledger has no backend, analytics or advertising.
  • No data is sold, shared or transferred to anyone.
  • Ledger's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time in Ledger ("Disconnect") or in Google Account → Security → Third-party connections.
